Wireframes (SVG)

This folder contains low-fidelity wireframes for the app. Each SVG is:

- Easy to view in any browser.
- Importable into Figma (File → Place Image or drag the SVG in).
- Shows layout blocks, labels, and primary actions.

Files

- home.svg — Landing page
- catalog.svg — Menu/catalog with search, categories, grid
- cart.svg — Cart with line items and summary
- checkout.svg — Checkout form + order summary
- payment.svg — Payment screen (Midtrans widget area)
- payment_result.svg — Payment result/redirect page
- orders_history.svg — Customer order history
- order_show.svg — Customer order detail
- admin_dashboard.svg — Admin overview
- admin_menu_items.svg — Admin: menu items index

Notes

- Catalog wireframe hides stock counts and login suggestion, per request.
- These are wireframes (not pixel-perfect). They communicate structure and flow.
- Want editable shapes in Excalidraw? I can also provide a .excalidraw scene on request.
